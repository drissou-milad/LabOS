# Example Dataset Gallery

**These are synthetic, not real embryo data.** This environment has no access to real
microscopy files or the full competition dataset, so these three examples were generated by
`scripts/make_gallery_examples.py` (using `mvp/make_test_data.py`'s synthetic-cell generator)
to stand in for what a real dataset gallery would contain. **Replace them with real embryo data
the moment you have it** — drop `.tif`/`.zip` files into this folder and they show up in the
gallery UI automatically (see `mvp/streamlit_app.py`).

| File | Title | What it actually contains (verified by running the real pipeline on it) |
|---|---|---|
| `embryo_a_division_rich.tif` | Division-rich | 3 cells; grows to 4 detected cells/frame after frame 3. The generator codes 2 division events; 1 is reliably detected by the current pipeline at default settings — an honest number, not the 2 originally intended (see below). |
| `embryo_b_crowded.tif` | Crowded | 9–10 detected cells/frame throughout, 0 divisions (none coded). Stresses the detector under density — a couple of cells merge into fewer detections by the last 2 frames, which is itself a real, useful demonstration of a real limitation, not a bug in the demo. |
| `embryo_c_sparse.tif` | Sparse | 2 cells/frame, stable, 0 divisions. The easy case. |

## Why "division-rich" doesn't show 2 divisions

The generator places a second division event at frame 5. Whether it's picked up depends on
exactly how close the new daughter lands to other cells and to `config.DIVISION_MAX_DISTANCE`
at that specific frame — with only 3 cells doing independent random walks in a small canvas,
that's not guaranteed every run. Rather than hand-tune the random seed until the "nicer" number
came out, the description above reports what actually happens when you run it, checked by
actually running it (`scripts/make_gallery_examples.py`'s own verification, and again by hand
while writing this file). If you regenerate these with a different seed, re-verify the
descriptions — don't assume they still match.

## Regenerating

```bash
python scripts/make_gallery_examples.py
```

Deterministic (fixed integer seeds per file, not Python's randomized string `hash()` — an
earlier version of this script used `hash(flavor)`, which is **not** reproducible across
Python process restarts by default, and was caught and fixed while building this).
